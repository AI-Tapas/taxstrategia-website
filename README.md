# Tax Strategia Partners website

Static, single-file website for taxstrategia.com, hosted on Cloudflare Pages.

| File | Purpose |
|---|---|
| `index.html` | The whole site: content, styles, fonts and scripts in one file. Editing guide is in the comment at the top. |
| `robots.txt` | Allows all crawlers and points to the sitemap. |
| `sitemap.xml` | Lists the homepage for search engines. |

## Deploying
Cloudflare Pages: no build command, output directory `/` (repository root).
